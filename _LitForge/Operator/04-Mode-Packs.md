# Mode Packs

Mode packs are additive sets of checks + templates tuned to a writing context.

Examples:
- **CORE** — the default backbone
- **NF_STRICT** — sourcing + claims discipline (facts ≠ vibes)
- **Fiction_Consistency** — continuity, character bibles, timeline checks
- **Series_Continuity** — long-form series drift control
- **Script_Performance** — pacing, beats, spoken-word clarity
- **Creative_Uniqueness** — guards against generic “AI slop” patterns
- **Audience_Engagement** — hooks, retention, payoff structure
- **DOA (Dead On Arrival)** — brutal kill/repair loop for weak concepts

## How users choose

Setup Wizard can recommend defaults based on a short vision statement.
Users can override:
- globally (whole vault)
- per project
- per stage

## Severity tiers

Most packs should support severity:
- **Light** (gentle)
- **Standard**
- **Hostile** (max red-team rigor)

LitForge’s philosophy: *let the user pick their pain level*.
